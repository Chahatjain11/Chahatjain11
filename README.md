## 🚀 Featured Projects

### 🅿️ QuickPark — Valet Parking Booking Platform *(2026 – Present)*
`Flutter` `Next.js` `TypeScript` `Prisma` `PostgreSQL` `Redis` `Socket.IO` `Firebase` `Razorpay`
- Owned the backend design of a **4-app platform** (customer, valet, manager, admin) built as a modular monolith.
- Prevented double-booking using **Redis distributed locks + PostgreSQL row-level locking**.
- Designed the relational schema and a **14-stage booking state machine** with **5-role access control**.
- Built **idempotent Razorpay payments** (retries never create duplicate charges), Firebase OTP auth, and real-time WebSocket status updates.

### 🔎 Advanced RAG Document Q&A *(2026)*
`Python` `LangChain` `Llama 3.1 8B (Groq)` `Cohere` `ChromaDB` `BM25` `Unstructured` `Streamlit`
- **Hybrid retrieval:** BM25 (30%) + vector search (70%) with Reciprocal Rank Fusion.
- **Multi-query generation** (3 variations per question) and **Cohere reranking** from 20 candidate chunks down to the top 5.
- Multi-format ingestion (PDF, DOCX, images, text) with table and OCR extraction.
- Streamlit chat UI with session management, persistent vector storage and source citations; deployment documented.

### ⚖️ Cyber-Saarthi — Fine-Tuned Legal AI Chatbot *(Sep 2025)*
`Python` `Hugging Face` `PEFT` `QLoRA` `BitsAndBytes` `PyTorch` `Streamlit`
- Fine-tuned **TinyLlama-1.1B with QLoRA (4-bit)** on a custom Indian cyber-law dataset (544+ Q&A pairs).
- Reached **60.2% accuracy** with a **93% reduction in evaluation loss**.
- End-to-end pipeline: automated dataset generation, LoRA adapters, conversation memory and streaming responses.

### 🏅 KreedaTech (Athleet) — Sports Talent Assessment App *(SIH 2025)*

### 📰 Patrakaarita — AI News Analysis System *(2025)*
